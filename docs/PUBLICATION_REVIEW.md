## 3. 資料切分、Leakage 與 Test Independence

| 實驗 | 使用情況與審查結論 |
|---|---|
| NumPy 基礎 | 純資料與標籤生成，不宣稱泛化評估 |
| KNN | 鄰居只來自 Train；以 Validation 選 K，再一次 Test；Training K=1 包含自身是已註明的訓練評估性質 |
| K-Means | 全資料無監督探索，不使用標籤，未宣稱獨立 Test 或挑出最佳 K |
| Linear／Logistic Regression | 各候選重新從相同參數訓練，只以 Train 更新；Validation 選學習率；Test 不參與更新與選擇 |
| Decision Tree | 只在 Train 建樹，Validation 選深度，Test 評估選定樹 |
| Random Forest | Bootstrap 只抽 Train，節點隨機選欄，Validation 選樹數，再評估 Test |
| L06 分類 | 四模型只用 Train 訓練，Validation 比較；Test 已切出但未評估，不補報或宣稱通過 Test |
| Gradient Boosting 回歸 | 起始平均與逐輪殘差只用 Train；Validation 選輪數，再評估 Test |
| XGBoost 案例 | 品牌 0/1 規則為事先指定，不使用目標統計；DMatrix 只含 Train；Validation 報分，Test 未評估 |
| Gaussian NB | Prior、Mean、Variance 只估 Train；固定設定評估 Validation／Test |
| Linear SVM | 標準化平均／標準差只來自 Train；各 C 只用 Train 更新，Validation 選 C，再 Test |
| PCA | 只由 Train 學中心與主方向；按事先示範門檻選最少維度，Validation 只觀察誤差，再 Test |

在已讀取與執行的預設流程中，未發現將 Validation／Test 標籤傳入訓練或依 Test 分數自動重新選模的路徑。產生標籤的真實規則只用於生成資料或圖中參考，沒有傳入模型作答案。

範例曾在學習過程反覆查看 Test，歷史人工決策是否完全未受影響無法由現有腳本證明。因此只宣稱**目前程式的流程隔離**，不宣稱這批固定 Test 是從未看過的最終盲測集。正式性能比較應另準備新的獨立 holdout。

PCA 的全資料分布圖僅作事後資料生成說明，不參與門檻或方向選擇；學習者若據全圖再調整設定，則需要重新檢視評估獨立性。

## 4. 尚未修正、刻意保留的限制

1. **SVM 最佳化精度**：固定步幅 0.05、500 輪不能保證收斂。只使用相同 Train、另以 0.005／10000 輪比對目標：C=0.1 約 0.086363→0.079055，C=1 約 0.556434→0.556430，C=10 約 2.538519→2.537740。這不是新的最佳設定、不是精確解證明，也沒有用 Test 重新選參數。保留原設定並揭露限制。
2. **樹的零改善規則**：06 遇零改善停止，XOR 會失敗；07／08 可先做零改善切分。測試同時確認這兩個有意保留的行為。
3. **森林候選欄位**：抽到的欄位都常數時直接停止，不重新抽其他欄。標籤依 bincount，限定非負整數；AdaBoost 更限定 0/1。
4. **Logistic BCE**：使用 epsilon clipping 保護 log，極端飽和時是有限的截斷損失；解析梯度對應原始 Sigmoid＋BCE。數值有限差分測試在未 clipping 的正常區間進行。
5. **API／數值範圍**：教學實作不是完整 sklearn 替代品，未對所有空批次、極大有限數、缺值或所有資料型別提供一致行為。輸入限制不能由預設範例成功外推。
6. **比較設計**：L06 Base Learners 容量與 RNG 消耗不完全配對，單次 Validation 不能證明 Variance 降低。XGBoost／LightGBM／CatBoost 未做三者實測競賽。
7. **學習狀態**：數學推導、陌生問題 Transfer、完整 Phase 01 整合驗收仍有待完成項目，個別 Lab 的 PASS 不是研究／生產品質認證。

- 初始資料夾沒有 `.git`、巢狀 Git 或上層 Repository，因此沒有既有提交或遠端歷史要改寫。

- 第三方套件依賴與已知授權資訊另見 THIRD_PARTY_NOTICES.md，未 vendoring 套件。
